## Test Automation Project – Urban Routes
### Objective
Design, implement, and execute automated end-to-end tests for the Urban Routes web application using Python, Selenium WebDriver, and the Page Object Model (POM) design pattern. The project focused on validating the complete ride-booking workflow while applying automation framework best practices.

---

### Scope of Testing
- Route configuration.
- Ride plan selection.
- Phone number registration.
- Payment method registration.
- Driver message functionality.
- Additional service selection.
- Ice cream ordering functionality.
- Vehicle search and assignment workflow.

---

### Tools Used
- Python
- Selenium WebDriver
- Pytest
- Git
- GitHub

---

### Activities Performed
- Designed and structured an automation framework using Python and Pytest.
- Implemented the Page Object Model (POM) architecture.
- Created reusable page classes and Selenium locators.
- Centralized test data and configuration management.
- Developed automated end-to-end test scenarios.
- Implemented setup and teardown methods for test execution.
- Configured environment validation before execution.
- Created reusable Selenium interaction methods.
- Automated user workflows from route selection to vehicle search.
- Executed automated test suites using Pytest.
- Applied version control and project management practices using Git and GitHub.
